# 0013: Keep layered provenance as ordered, reviewable findings

Status: accepted

Platform-independent knowledge must trace to company intent, and platform controls must trace to
platform-independent requirements. Run company alignment, control mapping and sibling comparison in
that order; pass same-run findings forward without first making them immutable relationships.

Source-adoption alignment is deterministic. Control parenting and sibling semantics are grounded,
bounded model outputs stored as inferred findings, never governance approval. The issue stage checks
the asymmetric cardinality contract, and execution statistics retain coverage and scan bounds.

This preserves replaceable inference and stale-finding lifecycle while making complete inferred
chains visible. See `docs\architecture.md` and `tests\unit\test_provenance.py`.
