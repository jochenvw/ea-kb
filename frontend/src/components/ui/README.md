# shadcn/ui primitives

Components are copied from the official `https://ui.shadcn.com/r/styles/new-york/` registry.
`LICENSE.md` retains the upstream MIT license; dependency licenses accompany the built application.
Local changes adapt the sheet overlay to shared theme tokens and format code with Prettier.
Color, radius and shadow utilities resolve to Bold Wikipedia through `tailwind.config.js`.
Regenerate deliberately from the registry and preserve accessibility and upstream attribution.
